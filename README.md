# Neural complex luminaires: representation and rendering

This is the mitsuba renderer code and scene files for neural complex luminaire. Now it NOT up-to-date yet. 

If you need the code or the scene ASAP, feel free to contact Yaoyi Bai at yaoyibai@ucsb.edu.

This paper originates from my master’s thesis, *Complex Luminaires Rendering Technique Studies* ([available here](https://scholar.google.com/scholar?cluster=4729715348623882617&hl=en&oi=scholarr)), which I conducted as the primary researcher under the supervision of Professor Norman Badler.
